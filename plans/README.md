## Findings considered and rejected (batch 2)

- **"Site paints black below the fold"**: rejected — reproduced during the
  audit but proven to be a stale capture surface in the browser tooling; the
  DOM, computed styles, and element sampling all showed correct rendering.
  Not a site bug; do not chase it.
- **Sync this repo's palette to the app repo's DESIGN.md values**: rejected —
  the shipped marketing palette is the owner-approved one; plan 014 instead
  rewrites DESIGN.md to describe what actually ships, with a provenance note.
- **MDX or raw HTML for portable article bodies**: rejected in favor of the
  JSON block schema — MDX reintroduces a compile step (defeats a database),
  raw HTML gives up the Guide* styling contract and adds an XSS sink.
- **Model state-specific pages in the CMS schema**: rejected —
  `docs/content-roadmap.md` explicitly holds state pages pending SEO volume
  and a revenue case; designing them in now contradicts a decision doc.
- **BEM rename of existing classes**: rejected — churn without user value;
  the `mh-page-` wrapper prefix (011) plus stylelint's class-pattern rule
  (012) give the needed namespace discipline.
