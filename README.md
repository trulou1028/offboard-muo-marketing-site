# Offboard Marketing Site

The public marketing site for [Offboard](https://offboard.co) — extracted from the
main app repo (`lumo-plan-builder`, where it lived at `/marketing/homepage`) into a
standalone Next.js project.

## Stack

- Next.js (App Router, TypeScript) — the homepage serves at `/`
- No Tailwind: the page ships its own fully scoped stylesheet
  ([MarketingHomepage.css](src/components/marketing/homepage/MarketingHomepage.css),
  `.marketing-homepage` scope, `--mh-*` tokens)
- Self-hosted variable fonts (Aspekta, Fraunces) in `public/fonts`
- [COPY.md](COPY.md) — **the master copy doc**: every user-facing string on the
  site, verbatim, plus language rules, the verified-facts ledger, and the copy
  decision log. Copy changes land there first (or in the same PR).
- [DESIGN.md](DESIGN.md) — the Clause design system this page follows
- [docs/site-architecture.md](docs/site-architecture.md) - the sitemap, page responsibilities, and migration gates

## Commands

```bash
npm run dev          # dev server on :3000
npm test             # vitest — the copy/compliance regression harness
npm run e2e          # Playwright against a production build
npm run build        # production build (/ prerenders static)
npm run imagery:dry  # show which page images would be (re)generated
npm run imagery      # generate missing imagery with OpenAI image gen
```

## Imagery

All photography and product renders are generated by
[scripts/generate-imagery.mjs](scripts/generate-imagery.mjs) into
`public/marketing/homepage/{raw,renders,collage}/`:

- **raw/** — documentary photography, style-locked to the approved hero photo
  (`~/Downloads/offboard-hero-real-life-image-1a.png`) via the images/edits
  reference input
- **renders/** — dark product illustrations, referenced against crops of the
  approved full-page mockup (`--crops` cuts those from
  `~/Downloads/Offboard marketing homepage · editable.jpg`)
- **collage/** — transparent torn-paper hero accents

The script discovers the newest `gpt-image-2*` model on the key at runtime and
refuses to fall back silently; the key comes from `$OPENAI_API_KEY` or the app
repo's `.env.local`. Regenerate a specific image with
`npm run imagery -- --only=raw/system-desk --force`. A full run costs ~$3–5.

## Deploys

GitHub `main` is the source of truth. Pushing a feature branch creates a Vercel
preview. Merging a verified pull request to `main` deploys to production
automatically:

**https://offboard.co** is the canonical production domain. The public
`offboard-muo-marketing-site.vercel.app` alias serves the same deployment, and
every route points search engines back to its canonical `offboard.co` URL.

Branch pushes get their own preview URLs, but those are gated behind Vercel SSO —
only team members signed into Vercel can open them.

Do not deploy production directly from a local worktree. In particular, do not
run `vercel --prod` with modified or untracked files. A production deployment is
considered synchronized only when Vercel reports the exact GitHub `main` commit
and does not report a dirty Git source.

Release workflow:

1. Create a feature branch.
2. Run `npm test`, `npm run build`, and `npm run e2e`.
3. Push the branch and verify the Git-backed Vercel preview.
4. Merge the pull request to `main`.
5. Confirm the production deployment commit matches GitHub `main`.

## Notes

- The page is deliberately backend-free — a test asserts zero network calls.
- Public routes are indexable. Deferred routes keep their own `noindex, nofollow`
  metadata until they are ready to enter the sitemap.
- `lucide-react` is pinned to the app repo's version so icon artwork matches.
- **This page has now diverged from the app repo.** It was last synced from
  `lumo-plan-builder` commit `88751f7a`, then rebuilt here (2026-08-12) to the
  17-section conversion architecture ("Offboard Landing Page layout and
  framework.pdf") with the dark editorial visual system from the approved
  full-page mockup. `ProductScenes.tsx`, `stages.ts`, and the toolkit/stage
  interaction logic still track the app repo; the page composition, sections
  05/07/08/11/16, and all imagery are authored here. When re-syncing from the
  app repo, port component/interaction changes — don't overwrite the page.
- The e2e suite waits for React hydration before clicking. Next server-renders
  the tab buttons, so a click can otherwise land before the listeners attach and
  be silently dropped — the Vite original had no such window.
