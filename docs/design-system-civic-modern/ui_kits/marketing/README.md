# Marketing site UI kit

Two surfaces, the two dials described in the style guide.

- **`Homepage.jsx`** — the jobseeker dial (warm). Ten bands in the order the style guide's Section rhythm page specifies: Paper hero, Mist, Paper, Sand, Forest deep (Lumo anchor), Paper, Paper deep, Paper with a Forest inset, Mist, Forest deep (final CTA anchor).
- **`Sponsor.jsx`** — the sponsor / B2B dial (institutional). Forest deep full-bleed hero, then Paper the rest of the way, denser type, a numbers table, fewer photos. Same tokens, same components, no new colors.
- **`app.jsx`** — click-through: the header links switch between the two pages ("Sponsor Offboard" opens the sponsor page, any other link returns to the homepage).

Open `index.html`. Everything is composed from the published components; no styling is re-implemented here.

## Placeholder imagery

Only one photograph was supplied (`assets/photo-hero-kitchen-table.png`, shot 01 in the style guide's shot list). It stands in for every photo slot in both pages. The remaining eight frames are described in the shot list and have not been shot.
