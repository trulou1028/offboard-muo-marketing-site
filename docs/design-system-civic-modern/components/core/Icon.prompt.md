Monochrome 1.5px-stroke line icon; use anywhere the page needs a glyph, never inside a colored disc and never filled.

```jsx
<Icon name="briefcase" size={20} color="var(--forest)" />
```

Icons come from Lucide (substituted — Offboard has no proprietary icon set). Set `base` to the relative path of `assets/icons` when the page is not served from the project root.
