The action control; use `primary` once per section, `secondary` beside it, `ai` for "Ask Lumo", `lumo` only for the final CTA on the dark anchor.

```jsx
<Button variant="primary">Get started free</Button>
<Button variant="secondary">See how it works</Button>
<Button variant="ai">Ask Lumo</Button>
```

Labels are sentence case and never end in a period.
